# V2.2 진행 UX 간소화

수정 파일: src/life/NarrativeApp.jsx, src/life/TypedStory.jsx, src/life/gameState.js, tests/narrative.test.js.

사건 진입 단계를 없앴습니다. 기존 연결 문장과 상황 설명은 한 화면에서 타이핑되며 선택지는 즉시 나타납니다. 선택 후 같은 장면 안에서 후속 이야기를 표시합니다. 기존 문자 단위 타이핑과 터치 즉시 표시는 유지하고, 표시 전용/자동 진행 옵션만 추가했습니다.

후속 문장의 타이핑이 끝난 뒤 길이에 따라 2.5~6초 유지하고 자동 이동합니다. 성장 전환은 1.5초 후 자동으로 사건을 엽니다. 기존 진입·다음 시기·성장 건너뛰기 버튼은 제거했습니다. 결과에는 자동 이동 타이머가 없습니다.

중복 입력은 상태의 사건 ID·단계 검사와 1회 실행 잠금으로 차단합니다. 타이머는 화면 해제 시 정리하며 초기화 확인창에서는 멈춥니다. 확인창을 닫으면 충분한 읽기 시간을 다시 제공합니다.

시나리오, 선택 문구, 나이 배치, 경로, 그래픽, 엔딩은 변경하지 않았습니다.

검증: 테스트 19개와 빌드 통과. 브라우저에서 20세 전체 9개 사건을 매번 더블클릭해 완주했고 기록은 정확히 9개였습니다. 후속 확인 클릭 없이 청소년기·성인기·결과 화면으로 이동했습니다. 결과 화면 정지와 다시 살아보기 버튼을 확인했습니다. 기존 192조합 상태 테스트도 통과했습니다.
