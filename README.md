## 설계
시작 → 설정(20~60세, 외형, 기질) → 어린 시절 3개 → 청소년기 3개 → 성인기 6개(진로 선택 포함) → 결과 → 초기화.
성인 사건의 나이는 19세~현재 나이 사이에 배분합니다. 20세처럼 구간이 짧으면 여러 사건이 같은 해에 일어납니다. 마지막 사건은 항상 현재 나이입니다.

선택 직후 후속 이야기를 보여주고, 읽은 뒤 다음 장면으로 넘어갑니다. 자동 타이머로 문장을 지우지 않습니다. 플레이 시간 3~5분은 목표이며 실제 관람객 읽기 속도에 따른 사용자 검증이 필요합니다.

진로 선택에는 태그가 없습니다. 다른 경로에서도 공통 가치 갈등과 동일 태그를 사용하며 장소·대사만 바뀝니다. 어린 시절의 약속, 도움 요청 방식, 청소년기의 계획 습관이 이후 대사에 반영됩니다. 기질은 첫 대사, 외형은 그래픽에만 영향을 줍니다.

0~100 점수와 성숙도 판정은 없습니다. 결과는 선택 기록과 태그 등장 횟수입니다. 각 장면의 태그 노출 횟수는 균등하지 않으므로 성향 간 우열 척도로 해석하지 않는다는 안내를 표시합니다. 리서치북 원본이 없어 제공된 정의만으로 작성한 임시 이야기입니다.

응답·나이·외형은 React 메모리에만 존재합니다. 처음으로 이동 또는 새로고침 시 초기화됩니다. 외부 전송·localStorage·유료 서비스·이미지 생성 API는 사용하지 않습니다. 프린터 연결은 미구현입니다.

## 검증
V1 7개 + V2 4개 테스트, 총 11개 통과. 빌드 성공.
자동: 20~60 모든 연령의 시간 순서·정확한 종료 나이, 4경로×4기질×3외형(48조합) 완주·태그 일관성·초기화, 기록 보존, 중복 선택 방지, 과거 선택의 후속 대사 반영.
브라우저: 20세/신중/고민 경로와 60세/호기심/대학 경로 전체 완주, 성장 전환·후속 반응·12기록·종료·초기화 확인. 390px 모바일 결과와 768px 태블릿 게임 가로 넘침 없음. 실기기 터치, 관람객 소요 시간, 실제 출력은 검증하지 않았습니다.

## 리서치 원본 반영 업데이트

이전 단계의 ‘리서치북 원본 없음’ 설명은 이제 해당하지 않습니다. 제공된 graduation_project_master_plan_coded_v5.xlsx의 05, 06, 15, 16 시트를 분석하고 src/life/research.json에 원문·정의·행동 분류·행 위치·파일 해시를 보존했습니다. 원본 Excel은 수정하지 않았습니다.

src/life/research-scenarios.js가 기존 장면 틀에 행동 중심 사건을 적용합니다. 모든 실제 선택에 behavior, sourceIds, sourceRanges, mappingStatus를 기록합니다. 게임 사건·나이·대사·후속 결과는 창작이며 조사 문장과 구분됩니다. B10 건강관리와 B12 도움 주고받기는 경향 연결 검토 상태로 남겨 여섯 태그 횟수에 임의로 추가하지 않습니다.

결과 타임라인의 ‘이 장면의 리서치 근거’를 펼쳐 선택별 원문을 확인할 수 있습니다. 원자료 기존 코딩과 행동→경향 초안은 별도 보존합니다. 모든 진로의 행동 코드와 태그는 동일하며 진로 선택은 미반영입니다. 상세 대응표는 outputs/리서치-시나리오-근거대응표.md에 있습니다.

추가 검증 후 총 테스트 14개와 빌드 통과. 실제 브라우저에서 취업 경로 완주와 검토 중 행동 별도 집계, 원자료 ID·행 표시 확인.
