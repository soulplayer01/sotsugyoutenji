# 어른이 된 순간

React + Vite + Tailwind CSS + Motion으로 만든 한국어 전시 체험입니다. 실제 24문항, 자동 진행, 여섯 성향의 탐색적 결과 시각화를 제공합니다.

## 실행

```sh
npm install
npm run dev -- --host 0.0.0.0 --port 5173 --strictPort
npm test
npm run build
```

이미 서버가 실행 중이면 중복 실행하지 마세요. 현재 미리보기 주소는 http://192.168.40.183:5173/ 입니다. 네트워크 변경 시 Vite가 출력하는 주소를 확인하세요.

## 데이터와 구조

- `src/data/adult_moment_questions_ko.json`: 제공받은 원본을 바이트 그대로 복사한 데이터
- `src/data/questions.js`: 원문을 변경하지 않고 질문별 선택지 ID만 추가
- `src/data/results.js`: 성향별 결과 문구와 탐색적 지표 안내
- `src/state.js`: 답변·입력 잠금·이전 문항·완료·초기화
- `src/App.jsx`: 기존 화면과 500ms 자동 이동, 타이머 정리, 질문 유형별 선택지
- `src/scoring.js`: 순수 채점 함수 `calculateResults(answers)`
- `src/Results.jsx`: 대표 경향·막대그래프·성찰·출력 준비·초기화 화면
- `src/print.js`: 프린터와 독립적인 `createPrintPayload(answers)`
- `src/styles.css`: 기존 색상과 터치 UI, 모바일·태블릿 배치
- `tests/flow.test.js`: 원본 무결성, 전체 매핑, 채점, 전환, 출력 구조 테스트

응답 구조는 `{ [questionId]: optionId }`입니다. ID가 다른 질문에 속하거나 24문항이 완성되지 않은 응답은 채점하지 않습니다. 질문 원문과 선택지 순서는 JSON을 따릅니다. 원본을 의도적으로 교체하면 무결성 테스트의 SHA-256도 검토 후 갱신해야 합니다.

## 채점 규칙

이 규칙은 작품의 탐색적 시각화를 위한 임시 규칙이며 심리학적으로 검증된 진단이 아닙니다.

- 회상형: 성향별 2문항 합계를 `(sum - 2) / 8 * 100`으로 정규화
- 상황형: 성향별 선택 횟수를 `count / 8 * 100`으로 정규화
- 최종: 두 점수를 0.5씩 반영
- 원래 수치로 내림차순 정렬, 최고점 동점은 모두 공동 대표
- 동일 점수의 표시 순서는 원본 성향 순서
- 화면 표시만 소수 첫째 자리로 반올림

## 자동 진행과 저장

선택 후 노란색·체크 표시를 500ms 보여준 뒤 자동 진행합니다. 중복 입력을 막고, 뒤로 가기나 화면 변경 시 타이머를 취소합니다. 이전 문항의 선택은 유지되며 같은 선택을 다시 누르거나 다른 답으로 바꿀 수 있습니다. 결과에서 마지막 답변을 수정하면 결과를 다시 계산합니다. 처음으로 돌아가거나 페이지를 새로고침하면 응답이 초기화됩니다. 서버·브라우저 저장소에 응답을 저장하지 않습니다.

## 출력 준비

`createPrintPayload(answers)`는 버전, 원본 데이터 버전, 58mm 용지 정보, 채점 규칙, 대표 경향, 원점수·정규화·최종 점수, 성찰 질문, 비진단 안내를 포함하는 JSON 직렬화 가능 객체를 반환합니다. 원시 답변이나 개인정보는 포함하지 않습니다. 실제 POS-58 연결·문자 인코딩·줄바꿈·ESC/POS 명령은 구현하지 않았습니다. 출력 버튼은 비활성화되어 있습니다.

## 검증

자동 테스트 7개 및 프로덕션 빌드 통과. 실제 브라우저에서 24문항 완주, 5지/4지 선택지, 이전 답변 유지·수정, 결과 재계산, 그래프 6개와 대표 경향, 출력 버튼 비활성, 처음으로 이동 후 초기화를 확인했습니다. 390px 모바일·768px 태블릿 뷰포트에서 결과/질문 가로 넘침을 확인했습니다. 실제 터치 기기 및 물리 프린터는 검증하지 않았습니다.
